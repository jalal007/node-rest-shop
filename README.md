# Creating a REST API with Node.js

A simple REST API built with **Node.js** and **Express.js** as a learning project to understand RESTful API development and backend fundamentals.

## Tech Stack

- Node.js
- Express.js
- JavaScript (ES6+)

## Getting Started

```bash
npm install
npm start
```

## Purpose

Built for learning REST API concepts, routing, and CRUD operations.
